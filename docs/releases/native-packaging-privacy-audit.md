# Native packaging privacy audit

- Native packaging recognises Ajv's reviewed public schema metadata beneath the
  exact Linux Debian, Linux portable and macOS bundle stage roots. Windows keeps
  the common app-stage layout.
- The exception retains its exact SHA-256, line and single `advert-body` rule.
  Configured personal markers, credentials and other privacy checks still run
  across the complete stage. Unknown paths and changed bytes fail closed.
- This resolves the vendor metadata false positive only. The independent sealed
  packaging gate remains required before native acceptance or publication.
  No workspace migration or credential change is required.

See [Supply-chain security](../SUPPLY_CHAIN_SECURITY.md) for the exact scope.
